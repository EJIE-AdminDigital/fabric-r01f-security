# User/Password Login with OTP
==========================================

## Add necessary otp projects on RESTWar pom.xml (f.e: r01PLATEAWebCORESecurityRESTServicesWar)

	<dependency>
		<groupId>r01.r01f.security.otp.core</groupId>
		<artifactId>r01fOTPCOREClasses</artifactId>
		<version>${r01f.version}</version>
	</dependency>
	
	<dependency>
		<groupId>r01.r01f.ejie</groupId>
		<artifactId>r01fLatiniaClasses</artifactId>
		<version>${r01f.version}</version>
	</dependency>

## Add otp properties component in config project if not present

**Path**: tck01Config --> tck01cConfig --> src/main/config --> tck01/components:

**tck01c.otp.dbpersistence.xml** pointing to **tck01c.dbpersistence.properties.xml**
	
	<?xml version="1.0" encoding="UTF-8"?>
	<componentDef>
		<numberOfPropertiesEstimation>10</numberOfPropertiesEstimation>
		<resourcesLoader type='CLASSPATH'/>
		<propertiesFileURI>tck01c/tck01c.dbpersistence.properties.xml</propertiesFileURI>	<!-- BEWARE with ClassPathLoader: USE relative paths -->
	</componentDef>
		  
## Add bootstrap config for OTP

this needs to be done in ResourceConfigBootstrap class: **TK01LoginRESTResourceConfigBootstrap**

	ServicesBootstrapConfigBuilder.forClient(OTPClientBootstrapConfigBuilder.buildClientBootstrapConfig())
																							.ofCoreModules(//... Service Layer
																									   		OTPBeanCoreBootstrapConfigBuilder.create()
																																						.from(xmlProps)
																																						.usingCommonNotifier()
																																						.build(),
																										   // ... Persistence layer ( db or hazelcast, in this case DB)
																										 	OTPDBPersistenceBeanCoreBootstrapConfigBuilder.buildCoreBootstrapConfig(xmlProps, TK01AppCodes.CORE_APPCODE)
																									   )
																							 .usingCommonCoreEventsHandler()
																							 .build()
## Add Optional parameter in ServiceImpl constructor

This needs to be added in Login Services Impl class: **TK01UserPasswordLoginServicesImpl**

Add paramenter to constructor --> `@Nullable final Optional<OTPService> otpService`

Also add parameter **otpService.orElse(null)** in super constructor of **delegateProvider*:

	_delegateProvider = _securityContext -> new TK01UserPasswordLoginServicesDelegate(_coreConfig,
																			              _modelObjectsMarshaller,
																			              _eventBus,
																			              _crudForUser,
																			              _crudForUserPasswordLogin,
																			              _crudForUserLoginEntry,
																			              _findForUserPasswordLogin,
																			              _usrPwdRecoverNotifierServices,
																			              _usrRegistrationNotifierServices,
																			              otpService.orElse(null));

## Add parameter for OTPService in LoginServicesDelegate

This needs to be added in Login Services Delegate class: TK01UserPasswordLoginServicesDelegate

add parameter to constructor --> `final OTPService otpService`

	public TK01UserPasswordLoginServicesDelegate(final ServicesCoreBootstrapConfigWhenBeanExposed coreCfg,
			                                     final Marshaller marshaller, final EventBus eventBus,
			                                     final CRUDServicesForUser<TK01User> crudForUser,
                                                 final CRUDServicesForUserPasswordLogin<TK00UserPasswordLogin> crudForUserPasswordLogin,
                                                 final CRUDServicesForUserLoginEntry<TK00UserLoginEntry> crudForUserLoginEntry,
                                                 final FindServicesForUserPasswordLogin<TK00UserPasswordLogin> findForUsrPwdLogin,
                                                 final UserPasswordRecoverNotifier usrPwdRecoverNotifierServices,
                                                 final UserRegistrationNotifier usrRegistrationNotifierServices,
                                         		 final OTPService otpService)

Also add parameter **otpService** in super constructor:

	super(coreCfg,
		  marshaller,
		  eventBus, 	
		  crudForUser, 
		  crudForUserPasswordLogin, 			 
		  crudForUserLoginEntry,
		  findForUsrPwdLogin,
		  usrPwdRecoverNotifierServices, 
		  usrRegistrationNotifierServices,
		  otpService);

## Once all is setup, the call must be to webflow login services:

Send OTP method:

	UserPasswordLoginResponseForWebFlow webFlowResponse = _presenter.onUserPasswordWebFlowLoginRequested(theLoginUrWithOTP,
																												 				loginId,password, 
																												 				authFactor,
																												 				toUrl);

Validate OTP number method:

	UserPasswordLoginResponseForWebFlow webFlowResponse = _presenter.onUserPasswordWebFlowLoginValidateAuthFactorRequested(theLoginOTPValidationUri,																															 
																											                   					 validationRequest,
																											                   					 toUrl);

## JPA Problems

When starting the server, if this error happens:

**No Persistence provider for EntityManager named persistenceUnit.tck01c.otp**

Make sure to have the file **tck01c.otp.persistence.xml** in proyect **tck01CommonCOREClasses** in path:

**src/main/resources --> META-INF --> jpa*

And **add resources folder on Java Build Path as a Source folder**.
